# Hof Spitzerüti

Eine minimalistische statische Website für den Hof Spitzerüti in Thurgau.

## Dateien

- `index.html` – Startseite
- `styles.css` – Einfaches Styling

## Kostenloses Hosting

Am einfachsten lässt sich die Seite mit GitHub Pages veröffentlichen:

1. Repository auf GitHub erstellen, z. B. `hof-spitzerueti`.
2. Diese Dateien ins Repository hochladen.
3. In den Repository-Einstellungen unter **Pages** als Branch `main` und Ordner `/ (root)` auswählen.
4. Speichern und kurz warten.

Anschließend ist die Seite unter `https://<dein-benutzername>.github.io/<repository-name>/` erreichbar.

## Alternative kostenlose Hosting-Optionen

- Netlify: Drag & drop des `HofWebsite`-Ordners auf die Netlify-Webseite.
- Vercel: Einfaches Deployment als statische Seite.

## Hinweis

Die Seite ist bewusst minimalistisch gehalten, komplett auf Deutsch und für eine einfache, schnelle Veröffentlichung optimiert.
